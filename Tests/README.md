# Тесты карточек RONINxBLOCK

Старые юнит-, mock- и интеграционные тесты заменены набором для карточек товаров.
В проекте 8 тестовых методов и 15 случаев с учётом параметров MSTest.
Контроллеры, представления и остальной код приложения не изменены.

## Запуск

Нужны .NET SDK с поддержкой `net9.0`, среды выполнения .NET/ASP.NET Core 9
и установленный PostgreSQL с `initdb`, `pg_ctl`, расширениями `citext` и `pg_trgm`.
Проверено на Windows с PostgreSQL 18. Docker не нужен.

Из папки, в которой лежит `ShoeStore.sln`:

```powershell
dotnet test ShoeStore.sln
```

PostgreSQL автоматически обнаруживается в `C:\Program Files\PostgreSQL\<версия>\bin`.
Для нестандартного расположения можно указать папку бинарных файлов:

```powershell
$env:POSTGRES_BIN = 'D:\PostgreSQL\18\bin'
dotnet test ShoeStore.sln
```

Только юнит-тесты, без установленной PostgreSQL:

```powershell
dotnet test ShoeStore.sln --filter 'FullyQualifiedName~CatalogDetailsTests'
```

## Что проверяется

| Метод | Проверка |
| --- | --- |
| `Details_InvalidId_ReturnsNotFoundBeforeOpeningDatabase` | ID 0, −1 и `int.MinValue`: `NotFoundResult`, ни одной попытки открытия БД. |
| `PublishedCards_OpenAnonymouslyAndShowDatabaseValues` | Все 16 опубликованных моделей открываются без cookies и перенаправлений. Бренд, название, цена, описание, основная фотография, выбранная расцветка и размеры сверяются с PostgreSQL. Размеры с нулевым остатком отсутствуют среди доступных вариантов. |
| `EveryTile_LinksToItsOwnProduct` | Каждая товарная плитка главной, «Новинок» и «Хитов» открывает свой товар; проверяются полный состав подборок, бренд и название. |
| `VariantGroups_ShowTheirOwnColorsPhotosAndDefaultSelection` | Расцветки, цветовые маркеры, фотографии каждой расцветки, порядок галереи и выбор варианта по умолчанию соответствуют БД. |
| `NoAvailableSizes_ShowsOutOfStock` | При нулевых остатках и при отсутствии записей размеров нет выбора размера и выводится «Нет в наличии». |
| `MissingDraftAndArchivedCards_Return404` | Отсутствующий, черновой и архивный товары возвращают 404 без карточки. |
| `CardImagesStylesAndScripts_LoadSuccessfully` | Ресурсы всех карточек возвращают 200, правильный тип и непустое содержимое, включая фотографии скрытых расцветок. |
| `OpeningCards_DoesNotChangeAnyCatalogRows` | Полный снимок строк товаров, брендов, категорий, расцветок, фотографий и размеров до и после открытия карточек совпадает. |

## Изоляция и данные

Интеграционные тесты запускают отдельный временный сервер PostgreSQL на свободном
локальном порту. Импортируют настоящую схему `Database/shoestore-schema.sql`,
создают собственные данные и проверяют путь папки сервера. Подключение приложения
и пользовательские секреты заменяются тестовым подключением. После тестов сервер
останавливается и его временная папка удаляется.

Архив содержит схему без данных рабочего магазина. Поэтому тестовые модели заданы
независимой таблицей в `CatalogFixture.cs`: все 16 ID макета, две расцветки для 9060,
нулевые остатки, пустые размеры, черновик и архив. Цены и описания намеренно отличаются
от демо-плиток, чтобы заметить статическую подмену данных карточки.

HTTP-тесты запускают настоящий `Program`, маршруты, Identity, MVC, Razor и PostgreSQL.
AngleSharp разбирает полученный HTML; Moq и отдельные mock-тесты удалены.
Эти проверки не исполняют JavaScript в браузере: поведение анимаций, кликов по
галерее и визуальная адаптивность в этот компактный набор не входят.
